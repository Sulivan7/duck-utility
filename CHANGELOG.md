# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-10-16

### Added

- `/smoke <map> <position>` command that shows a smoke lineup with GIFs (#10)
- Autocomplete for maps and positions (#12)
- Embed responses, plus the `/maps` and `/help` commands (#14)
- `/ping` command to check if the bot is online (#6)
- 55 smoke lineups on 7 maps, from Tactical Toss Tutor (#8)
- Automated tests with pytest (#8)
